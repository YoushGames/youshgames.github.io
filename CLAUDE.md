# Yoush Games website

Static GitHub Pages site: studio landing page + one privacy policy page per game.

Before adding a game, changing a game page, or touching icons/fonts/assets, read and follow
[GAME_PAGES.md](GAME_PAGES.md). It covers the audit, policy content, design, asset recipes,
the page template and verification.

Never commit or push without the user's explicit go-ahead: pushing to `main` publishes the live site.
